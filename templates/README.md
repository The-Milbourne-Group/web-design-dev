**Applies to:** Anyone starting a recurring document.

**Review trigger:** Template added; parent SOP or domain document changed.
**Related:** `SOP_INDEX.md`, `governance/KNOWLEDGE_ARCHITECTURE.md`

---

## Rules

1. **A template is a starting point, never a completed document.** Adapt it to
   actual context.
2. **A filled-in example is not evidence.** Placeholder values are not company
   facts.
3. **Never leave a placeholder in a delivered document.** An unfilled field is
   a defect.
4. **Never invent a value to fill a field.** If it is registered in
   `OPEN_QUESTIONS.md`, write "to be determined" and escalate.
5. **A template never overrides policy.** Where a template and its governing
   document differ, the governing document wins and the template is defective.
