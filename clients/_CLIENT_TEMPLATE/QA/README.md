# QA RECORDS — <CLIENT>

Verification records produced under `sops/delivery/QA.md`.

One record per QA pass, named `YYYY-MM-DD-<deliverable>.md`.

Every record must state what was checked, what passed, what failed, and
**what was not checked**. A record without the "not checked" section implies
complete coverage and is dishonest (`MASTER.md` §9.3).
